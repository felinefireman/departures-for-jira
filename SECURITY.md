# Security

## Reporting

Report security issues to the maintainers via GitHub's private vulnerability
reporting. Do not file public issues for security concerns.

## Counts only

Departures never requests issue titles, assignees, descriptions, comments, or
any field values from Jira. Every query uses `search/approximate-count`, which
returns only a number. The board exposes issue counts only, safe for public
placement on an office wall.
