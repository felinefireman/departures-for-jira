# Screenshots

These come from the demo board: `npm run demo`, then capture `?scene=<letter>&rotate=0` at
1920×1080. Synthetic data, so no Jira account is needed. Hide the DEMO DATA chip for the shot
with `page.addStyleTag({ content: "#demoChip { display: none !important }" })`; don't change
the product to do it, since a live board should keep that chip obvious.

Scene letters follow the `scenes` array of whichever config you're running, `a` first.
